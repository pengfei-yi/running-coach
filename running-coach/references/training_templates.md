# Training Plan Templates

## Periodization Structure

All plans follow 4-phase periodization:

| Phase | Focus | Intensity | Volume |
|-------|-------|-----------|--------|
| **Base (30-40%)** | Aerobic foundation, consistency, form | Low (Z1-Z2) | Progressive build |
| **Build (25-30%)** | Introduce quality: tempo, intervals | Medium (Z3-Z5) | 80-90% of peak |
| **Peak (20-25%)** | Race-specific workouts, confidence | High (Z3-Z5) | 100% peak |
| **Taper (10-15%)** | Freshness, sharpness | Maintain intensity, cut volume | 50-60% of peak |

## Workout Type Reference

| Code | Name | HR Zone | Purpose |
|------|------|---------|---------|
| E | Easy Run | Z1-Z2 | Recovery, base building |
| L | Long Run | Z2 | Endurance, mental toughness |
| T | Tempo Run | Z4 | Lactate threshold improvement |
| I | Intervals | Z5 | VO2max development |
| R | Repetitions | Max | Running economy, speed |
| M | Marathon Pace | Z3-Z4 | Race-specific endurance |
| F | Fartlek | Variable | Fun, varied stimulus |
| H | Hills | Z5 | Strength, power |
| S | Strides | Sprint | Neuromuscular coordination |

## Plan Templates by Distance

### 5K Plan (12 weeks)
- Base: 4 weeks — Easy runs + strides, 70% volume
- Build: 4 weeks — Intervals + tempo + long run, 85% volume
- Peak: 3 weeks — Race-specific intervals, 100% volume
- Taper: 1 week — Easy + short intervals, 60% volume

### 10K Plan (13 weeks)
- Base: 4 weeks — Easy + strides + long run, 65% volume
- Build: 5 weeks — Tempo + intervals + long run, 85% volume
- Peak: 3 weeks — Race pace + long run, 100% volume
- Taper: 1 week — Easy + strides, 55% volume

### Half Marathon (17 weeks)
- Base: 6 weeks — Easy + long run + strides, 60% volume
- Build: 5 weeks — Tempo + long run + intervals, 80% volume
- Peak: 4 weeks — Marathon pace + long run, 100% volume
- Taper: 2 weeks — Easy + strides, 50% volume

### Marathon (22 weeks)
- Base: 8 weeks — Easy + long run + strides, 55% volume
- Build: 6 weeks — Tempo + long run + marathon pace, 75% volume
- Peak: 5 weeks — Marathon pace + long runs, 100% volume
- Taper: 3 weeks — Easy + marathon pace + strides, 50% volume

## Weekly Schedule Pattern (5 days/week)

| Day | Primary | Notes |
|-----|---------|-------|
| Mon | Off/Easy | Recovery from weekend |
| Tue | Quality | Intervals or tempo |
| Wed | Easy | Zone 1-2 recovery |
| Thu | Moderate | Tempo or marathon pace |
| Fri | Easy | Zone 1-2 or off |
| Sat | Long Run | Main endurance session |
| Sun | Off | Full rest |

**Key rules**:
- No hard workouts on consecutive days
- Long run is non-negotiable weekly session
- Easy days should be truly easy (conversational pace)
- Cut long run distance during taper (50-70% of peak)
